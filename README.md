## 🏦 Bank Loan Report Dashboard


## 📌 Project Overview

The Bank Loan Report Dashboard is an end-to-end financial analytics project designed to analyze loan performance, funding distribution, and credit risk patterns.

This project transforms raw loan application data into actionable insights for banking decision-makers by tracking:
- Loan application trends
- Funded vs received amounts
- Good vs bad loan ratios
- Interest rate behavior
- Debt-to-Income (DTI) analysis
- State-wise and purpose-wise loan distribution

The dashboard enables financial institutions to monitor performance, manage risk, and optimize lending strategy.

---

## 🛠 Tech Stack

- SQL Server – Data extraction & transformation
- Power BI – Data modeling & interactive dashboard
- DAX – KPI calculations
- Excel/CSV – Raw dataset

## 2️⃣ Overview Page – Business Performance Insights
### 📅 Loan Applications by Month

- Steady growth trend throughout the year
- December peak at 4.3K applications

🗺 State-wise Loan Distribution
- High concentration in selected states
- Enables regional performance tracking

⏳ Loan Term Analysis
- 36 months: 73.2%
- 60 months: 26.8%

👔 Employee Length Impact
- Highest applications from 10+ years experience (8.9K)

🎯 Loan Purpose Analysis

Top purposes:
- Debt consolidation (18K)
- Credit card (5K)
- Home improvement (3K)

🏠 Home Ownership Impact
- Rent: 18K
- Mortgage: 17K
- Own: Smaller segment

3️⃣ Details Page – Granular Loan Records

Provides transaction-level insights including:
- Loan ID
- Purpose
- Home Ownership
- Grade & Sub-grade
- Funded Amount
- Interest Rate
- Installment
- Amount Received
- Enables deep-dive credit and performance analysis.
